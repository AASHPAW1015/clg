# Student Profile System (Java)

Console app that takes a student's name and marks for 5 subjects, then prints a full report card.

## Features

- **Name + 5 subject marks input** via `Scanner`
- **Input validation** — rejects non-numeric input and marks outside 0–100
- **Total marks** out of 500
- **Percentage** calculation, formatted to 2 decimals
- **Average marks** per subject
- **Grade assignment** — A / B / C / D / F based on percentage
- **Pass / Fail result** — pass mark is 40%
- **Best & weakest subject** — found in a single array pass
- **Weak subject flagging** — any subject under 40 tagged `(weak)` and counted

## Grading Scale

| Percentage | Grade |
| --- | --- |
| 90 and above | A |
| 75 – 89 | B |
| 60 – 74 | C |
| 40 – 59 | D |
| Below 40 | F |

## Concepts Used

Arrays · Loops · If-else ladder · Scanner input · `printf` formatting · Basic input validation
